# 🚀 Trudo – Verified Crowdfunding & Event Platform

**Trudo** is a full-stack **MERN application** built to bring **trust, transparency, and verification** into online crowdfunding and event management.

🌐 **Live Website:** https://www.trudo.shop/  
💻 **GitHub Repository:** https://github.com/lie-fde/Trudo_Mern  

---

## 🔍 Problem Statement

During disasters and emergency situations, many fundraising campaigns appear online.  
However, donors often face:

- ❌ Fake or unverified campaigns  
- ❌ No clarity on fund usage  
- ❌ Lack of accountability  

**Trudo solves this by introducing admin verification and controlled visibility.**

---

## ✨ Key Features

### 🫶 Crowdfunding
- Users can raise donation campaigns  
- Campaigns are visible only after admin approval  
- Secure donation flow using **Razorpay**

### 🎟️ Events
- Users can host events (admin verification required)  
- Users can buy event tickets  
- Email confirmation is sent for ticket purchases  

### 🛡️ Admin Panel
- Approve / reject campaigns and events  
- Block or manage users  
- Ensure platform authenticity  

### ⚙️ General
- Role-based access control  
- Secure authentication  
- Clean, responsive UI  

---

## 🔁 Application Flow

1. User registers & logs in  
2. User raises a campaign or hosts an event  
3. Admin verifies submitted details  
4. Approved listings become public  
5. Users donate or purchase tickets  
6. Ticket buyers receive email confirmation

## 🧰 Tech Stack

### 🎨 Frontend
- React  
- Redux Toolkit  
- Tailwind CSS  
- React Router  
- Axios  

### 🖥️ Backend
- Node.js  
- Express.js  
- MongoDB & Mongoose  
- JWT Authentication  
- Razorpay Payment Gateway  
- Nodemailer (Email notifications)  
- Cloudinary (File uploads)  

### ☁️ Deployment
- Frontend: AWS Amplify  
- Backend: AWS EC2  
- Reverse Proxy: Nginx  
- Process Manager: PM2
